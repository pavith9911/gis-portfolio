# Plot Plan Overlay

A land-subdivision plan georeferenced onto satellite imagery: status filters, price/size filters, plot drawer with enquiry text, plan opacity, measure tool and CSV export.

## Run it

Open `index.html` in a browser (or host the folder on GitHub Pages). No build step. Needs internet for the Leaflet CDN and map tiles.

## Built with

Leaflet 1.9.4, SVG `L.imageOverlay`, Esri World Imagery / World Street Map base maps, vanilla JS.

## Data

A **fictional** estate ('Green Valley Estate', 32 plots) generated by `build_site.py`. A real client plan is traced to SVG and georeferenced with 2-3 control points.

## Notes

`python build_site.py` regenerates `data/plots.js` and `data/site_plan.svg`.
