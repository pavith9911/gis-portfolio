# Satellite Swipe Viewer

Compare two dates of daily NASA satellite imagery with a draggable divider (keyboard accessible), presets such as the Aral Sea, layer choice and one-year-apart shortcut.

## Run it

Open `index.html` in a browser (or host the folder on GitHub Pages). No build step. Needs internet for the Leaflet CDN and map tiles.

## Built with

Leaflet 1.9.4, NASA GIBS WMTS tiles, two map panes clipped with CSS `clip: rect()`.

## Data

Live NASA GIBS imagery (MODIS Terra/Aqua, VIIRS, false colour). Daily mosaics can have gaps or clouds.
